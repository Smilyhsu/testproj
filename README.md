# 👟 中央洗鞋廠自動化產能調度與動態模擬系統

這是一個專門為大型、中央自動化洗鞋廠開發的**即時產能估算與動態調度排程工具**。能協助營運主管根據每日接單量，動態調配洗鞋機運作次數、烘乾房空間與兩種不同效率鞋架（A架/B架）的建置決策。

## 🌟 核心功能
1. **即時診斷**：隨意輸入洗鞋機、烘乾房數量，系統會自動比對「清洗時速」與「烘乾時速」，判定廠線是否會發生嚴重塞車。
2. **走馬燈流水線模擬**：系統會自動模擬 `08:00` 起逐時的滾動數據，精準算出**「外頭暫存區（排隊濕鞋）」在幾點會達到最高峰**，作為工廠採購推車與空間規劃的依據。

## ⚙️ 如何在本地執行
1. 下載本專案解壓後的 `index.html`。
2. 直接用任何瀏覽器（Chrome, Edge, Safari）雙擊打開該檔案。
3. 點選網頁上的**淡黃色輸入框**直接更改數據，下方的圖表與診斷結果會 100% 自動聯動即時重算。

## 🌐 怎麼利用 GitHub Pages 變成免費用手機開啟的線上工具？
如果您想讓全公司或團隊用手機隨時點開計算，請跟著以下步驟：
1. 在 GitHub 上建立一個全新的儲存庫 (Repository)。
2. 將 `index.html` 檔案上傳至該儲存庫的主分支 (main/master)。
3. 前往該儲存庫的 **Settings (設定)** -> 左側選單點選 **Pages**。
4. 在 Build and deployment 下方，將 Source 設為 **Deploy from a branch**，並選擇 **main** 分支與 **/ (root)** 資料夾，點選 Save。
5. 稍等 1 分鐘，GitHub 就會產生一個專屬的網址（例如：`https://你的帳號.github.io/專案名稱/`），打開就能直接線上使用了！
